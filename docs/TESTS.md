# TESTS

0) Подготовка
Открой терминал в папке проекта ExamTickets (где ExamTickets.csproj).
Запусти:
PowerShell
dotnet run
Убедись, что появилось:
Для выхода нажмите ESC.
1) Тест: базовый ввод + создание файла
Цель: файл создаётся, запись добавляется.

Введи:
Last name: Ivanov
First name: Ivan
Программа должна вывести: Билет № X (где X от 1 до 20).
Должно быть сообщение: Запись сохранена...
Проверь в проводнике: появился файл journal.xlsx.
Открой Excel и проверь:
есть шапка из 4 столбцов
есть 1 строка с Ivanov Ivan, номером билета и датой.
2) Тест: пустой ввод (валидация)
Цель: пустые строки запрещены.

На Last name: нажми просто Enter.
Ожидаемо: Поле не может быть пустым. Повторите ввод.
Введи фамилию с пробелами, например:
Petrov  
На First name: тоже сначала Enter (пусто) → должно попросить снова.
Введи:   Petr  
В Excel должно записаться без крайних пробелов: Petrov, Petr.
3) Тест: диапазон билетов
Цель: только 1..20.

Добавь 5–10 студентов быстро.
Каждый раз смотри Билет № ....
Ни разу не должно быть 0, 21, отрицательных и т.д.
4) Тест: выход по ESC
Цель: корректное завершение.

Когда программа ждёт Last name:, нажми ESC.
Ожидаемо: Выход из программы.
Программа завершилась без ошибки.
5) Тест: дозапись после перезапуска
Цель: старые строки не перезаписываются.

Запусти снова:
PowerShell
dotnet run
Добавь ещё 2 студентов.
Открой journal.xlsx.
Проверь:
старые записи остались
новые добавились в конец
общее число строк увеличилось.
6) Тест: сохранение после каждой записи (аварийная остановка)
Цель: данные не теряются.

Запусти программу.
Введи одного студента и дождись Запись сохранена.
Не закрывая нормально, принудительно убей процесс:
Ctrl+Shift+Esc → Диспетчер задач → найти dotnet/терминал → Снять задачу.
Открой journal.xlsx.
Последняя запись должна быть в файле.
7) Тест: файл открыт в Excel (ошибка доступа)
Цель: программа не падает.

Открой journal.xlsx в Excel и оставь открытым.
Запусти/оставь запущенной программу и попробуй добавить студента.

понятная ошибка про недоступность файла
предложение закрыть Excel и повторить
